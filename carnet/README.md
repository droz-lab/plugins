# Carnet

Reflexions, idees et notes de chacun, pour que les trois les aient sous la main.

- Un dossier par personne : `carnet/<prenom>/`.
- Un fichier par sujet : `AAAA-MM-JJ-sujet.md`, court, en francais.
- `carnet/<prenom>/PROFIL.md` : ton contexte de travail (niveau en code, DAW, systeme, facon d'ecouter, plugins de reference). L'assistant le remplit avec toi a ta premiere session et le relit ensuite. Depot public : rien de personnel.
- On n'ecrit que dans son dossier. Pour reagir a la note d'un autre : une note chez soi qui la cite, ou un commentaire sur sa PR.
- Une idee qui devient une decision va dans le `NOTES.md` du plugin concerne ou dans `docs/PIEGES.md`.
- Une PR qui ne touche que `carnet/` ne compile rien : elle passe en moins d'une minute.

Ca peut se demander en une phrase : "Mets cette reflexion dans mon carnet et ouvre une PR."
