# DROZ LAB

Plugins audio VST3 du collectif [Droz](https://drozrecordz.com).

**[Telecharger le Droz Software Center](https://github.com/droz-lab/plugins/releases/download/dernier/Droz-Software-Center-Setup.exe)** (Windows) : installe et met a jour tous les plugins d'un clic.

| Plugin | Version | Par | Ce que ca fait | Installer |
|---|---|---|---|---|
| **[Droz Courbes](https://github.com/droz-lab/plugins/tree/zomban/courbes-famille/plugins/courbes)** | 0.4.0 essai | Zomban | Generateur de courbes synchronisees au tempo | [Windows](https://github.com/droz-lab/plugins/releases/download/dernier/Droz-Courbes-Setup.exe) |
| **[Droz Master](https://github.com/droz-lab/plugins/tree/claude/eloquent-carson-svfmmm/plugins/master)** | 0.1.0 essai | YoY | Chaine de mastering a modules reordonnables | [Windows](https://github.com/droz-lab/plugins/releases/download/dernier/Droz-Master-Setup.exe) |
| **[IDGems](https://github.com/droz-lab/plugins/tree/yoy/idgems-plugins/plugins/idgems)** | 0.1.0 essai | YoY | Machine a glitch randomisable : rack d'effets IDGems | [Windows](https://github.com/droz-lab/plugins/releases/download/dernier/IDGems-Setup.exe) |
| **[IDGems Stretch](https://github.com/droz-lab/plugins/tree/yoy/idgems-plugins/plugins/stretch)** | 0.1.0 essai | YoY | Gel de frame sonore a un rate, grain et texture | [Windows](https://github.com/droz-lab/plugins/releases/download/dernier/IDGems-Stretch-Setup.exe) |
| **[Markov](https://github.com/droz-lab/plugins/tree/yoy/markov-generateur/plugins/markov)** | 0.1.0 essai | YoY | Générateur MIDI markovien sur 8 pistes | [Windows](https://github.com/droz-lab/plugins/releases/download/dernier/Markov-Setup.exe) |

"essai" : plugin en chantier, refait a chaque mise a jour de sa branche. Windows signale un editeur inconnu : "Informations complementaires" puis "Executer quand meme".
