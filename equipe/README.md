# Equipe : un journal de bord par personne

Chacun a son dossier `equipe/<prenom>/` (prenom en minuscules, sans accent) avec un `JOURNAL.md`.

- Le journal appartient a son auteur : personne d'autre n'y ecrit, ni humain ni Claude.
- Une entree par session, la plus recente en haut : date, sur quoi on a travaille, lien de la PR ou du run, ce qu'il faut ecouter ou decider, idees pour la suite.
- Pas de binaire ni de WAV ici : les plugins compiles sont dans Actions et Releases, les rendus dans l'artifact `apercu`.
- Une lecon utile a tous va dans `docs/PIEGES.md`, pas dans le journal.

Nouveau membre : demande a ton Claude "cree mon journal de bord", il copie l'en-tete de `yoan/JOURNAL.md`.
